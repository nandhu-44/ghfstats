ghfstats

Who follows you on GitHub, who doesn't follow back, and who unfollowed you.

Continue with GitHub Sign in to track your own account every day: catch unfollows without visiting, see history graphs and richer follower details.
GitHub token (optional, for bigger accounts)

Without a token GitHub allows 60 requests an hour, enough for about 3,000 followers plus following. A token with no scopes raises that to 5,000. It is sent only to api.github.com and stays in this browser.

Change history

GitHub has no unfollow API, so ghfstats saves a snapshot in this browser each time you check and compares it with the last one.
