ghfstats

What ghfstats stores

Without signing in

Checking a username runs in your browser. Follower lists and snapshots are saved in your browser's local storage only. An optional token stays in your browser and is sent only to GitHub.

When you sign in with GitHub

ghfstats asks GitHub for no extra permissions. It can only read what is already public on your profile.

To track your account every day, it stores:

  • your GitHub user id, username, display name and avatar link
  • your GitHub sign-in tokens, encrypted, so the daily snapshot can run while you're away
  • your current followers and following (their public usernames, ids and account types)
  • follow and unfollow events with dates, and a daily count of followers, following and mutuals

Only your own account is tracked. Looking up someone else's username is never saved on the server. Follower insights are fetched when you ask for them and are not stored. When you look up a username while signed in, the lookup uses your GitHub sign-in so you get a higher limit; it isn't stored either.

Follows on GitHub are public, so there is no hidden follower data for ghfstats to show. Nothing is sold, shared or used for advertising.

Stopping

Signing out ends the session in that browser; daily tracking continues. Delete my data on your dashboard removes everything above and revokes ghfstats' access on GitHub. You can also revoke access any time from GitHub's settings under Applications.
